# Print validation results list

Print validation results list

## Usage

``` r
# S3 method for class 'qti_validation_results_list'
print(x, ...)
```

## Arguments

- x:

  A `qti_validation_results_list` returned by
  [`verify_qti()`](https://shevandrin.github.io/rqti/maxima-preview/reference/verify_qti.md).

- ...:

  Unused additional arguments.

## Value

`x`, invisibly. Results are already printed by
[`verify_qti()`](https://shevandrin.github.io/rqti/maxima-preview/reference/verify_qti.md).
